# PTA Documents

Python-Bibliothek, die Dokumente in Markdown umwandelt und aus Markdown Dokumente im Design der PTA erzeugt — Word (`.docx`), PowerPoint (`.pptx`) und PDF auf Basis der offiziellen PTA-Vorlagen. Eigenständig weitergeführte Portierung von DocLibs (.NET) nach Python 3.

## Für KI-Assistenten und Mitwirkende

Beginne bei [AGENTS.md](AGENTS.md).

## Für Anwender

- [docs/anleitung.md](docs/anleitung.md) — einrichten, Dokumente in `documents/` schreiben,
  `./run.sh generate documents/<thema>`.
- [docs/ki-anleitung.md](docs/ki-anleitung.md) — Anleitung für eine KI, die im Klon Dokumente
  erzeugt.
