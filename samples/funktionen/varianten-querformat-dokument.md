# Querformat mit Deckblatt

Das Querformat hat ein eigenes Deckblatt; breite Tabellen und Bilder haben mehr Platz.
`kennzeichnung: vertraulich` setzt „VERTRAULICH“ unter das Logo jeder Seite und auf das
Deckblatt unter „Autor, Ort, Datum“.

| Variante | Deckblatt | Format |
| :------- | :-------: | :----- |
| `hoch` | ja | A4 hoch |
| `hoch-ohne-deckblatt` | nein | A4 hoch |
| `quer` | ja | A4 quer |
| `quer-ohne-deckblatt` | nein | A4 quer |
