# Hochformat ohne Deckblatt

Titel und Untertitel stehen in der Kopfzeile, ein Deckblatt und ein Inhaltsverzeichnis gibt es
nicht (`inhaltsverzeichnis: nein`).

## Ohne Typografie

Mit `typografie: nein` bleiben "gerade Anführungszeichen", ' - ' und drei Punkte... so, wie sie
geschrieben sind.

## Ohne Hervorhebung

Mit `syntaxhervorhebung: nein` bleibt Code einfarbig:

```python
print("einfarbig")
```
