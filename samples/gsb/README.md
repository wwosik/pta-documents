# Beispiel: Hauptbeskidenweg (GSB)

Beispielinhalt auf Deutsch über den Główny Szlak Beskidzki, Polens längsten Fernwanderweg in
den Bergen — zum Ausprobieren der Generatoren mit echten Fotos.

| Datei | Zweck |
| ----- | ----- |
| `gsb-bericht.md` | Bericht für Word (Deckblatt, Inhaltsverzeichnis, Tabellen, Abbildungen, Fußnote) |
| `gsb-praesentation.md` | Präsentation für PowerPoint (Titel-, Trenn-, Text-, Tabellen-, Bild- und Abschlussfolien) |
| `images/` | Fotos von Wikimedia Commons (Creative Commons) |
| `QUELLEN.md` | Textquellen, Urheber und Lizenzen der Fotos |

Erzeugen (Ergebnis in `.tmp/samples/gsb/`):

```sh
./run.sh generate-samples gsb
```
