# Dokumentation

Wie die Anwendung heute tatsächlich funktioniert — nicht, wie sie funktionieren soll. Pläne
liegen in `spec/`.

Was hier nicht mehr zum Code passt, ist ein Fehler: entweder in derselben Änderung mitziehen
oder löschen.

- [Verwendung](verwendung.md) — Generatoren und Konverter aufrufen, Front Matter, Zuordnung der Markdown-Blöcke.
- [Anleitung für Anwender](anleitung.md) — vom Klonen bis zum fertigen PTA-Dokument.
- [Anleitung für KI-Assistenten](ki-anleitung.md) — Regeln und Syntax für eine KI, die mit der Bibliothek Dokumente erzeugt.
